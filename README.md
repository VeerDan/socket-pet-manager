# socket-pet-manager

## Требования

- `make`
- `gcc`
- `ncurses` 

## Сборка проекта

Для сборки server используйте

```sh
make server
```

Для сборки client используйте

```sh
make client
```

Сборка server и client:

```sh
make
```

После исполнения получаются два файла:

- `server.exe`
- `client.exe`

Чтобы очистить артефакты сборки, используйте:

```sh
make clean
```

## Запуск приложения

Запуск сервера:

```sh
./server.exe
```

Запуск клиента:

```sh
./client.exe
```

Клиент подключается к `127.0.0.1:8000`. Сервер работает только с одним клиентом. После отключения, ждёт следующего подключения от другого клиента. Если с сервером начали работу два клиента, работа со вторым из подключившихся начнётся после отключения первого.
