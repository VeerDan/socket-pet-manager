# socket-pet-manager

## Требования

- `make`
- `gcc`
- `ncurses` 

## Сборка проекта

Сборка server и client:

```sh
make
```

После исполнения получаются два файла:

- `server.exe`
- `client.exe`

Чтобы очистить артефакты сборки:

```sh
make clean
```

## Запуск приложения

Запуск сервера:

```sh
./server.exe
```

Запуск клиента:

```sh
./client.exe
```

Клиент подключается к `127.0.0.1:8000`. После отключения клиента от сокета сервер ждёт следующего подключения.
